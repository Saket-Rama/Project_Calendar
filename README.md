# 📅 Calendar App

A simple calendar application built using Python.

## Features

- View a specific month
- View an entire year
- Simple menu-based interface
- Uses Python's built-in `calendar` module

## Technologies Used

- Python
- Calendar Module

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the project in VS Code.
4. Run `calendar_app.py`.

## How It Works

The application provides three options:

1. View Month
2. View Entire Year
3. Exit

The user selects an option and provides the required year/month.
